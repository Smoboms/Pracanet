# Pracanet (restructure/vercel)\n\nScaffold Vite + React criado para organizar o código e permitir deploy no Vercel.\n\nComo rodar localmente:\n1. Instale dependências:\n   npm install\n\n2. Rodar em desenvolvimento:\n   npm run dev\n\n3. Build / preview:\n   npm run build\n   npm run preview\n\nNotas:\n- O projeto inclui um cliente "base44" mock (src/api/base44Client.js) para permitir execução local sem backend.\n- A branch de trabalho criada: restructure/vercel\n- Se quiser que eu faça o push e abra o PR com estes arquivos, responda: "Pode commitar e abrir PR".
